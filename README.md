# 保洁外包考核站

甲方对保洁外包人员的「问题拍照 → 扣分 → 扫码整改 → 老板汇总」一站式闭环。
零原生依赖（Node + Express + JSON 文件持久化），开箱即用。

## 角色

| 角色 | 入口 | 默认账号 | 能做什么 |
| --- | --- | --- | --- |
| 甲方管理员 | `/login.html` | `admin / admin123` | 员工管理、上传问题照片与扣分、生成整改链接/二维码、删记录、改设置 |
| 老板 | `/login.html`（选「老板」） | `boss / boss123` | 只读：按员工查看问题/整改图片对、总扣分、整改进度 |
| 外包员工 | 管理员发送的链接/二维码（`/e.html?token=...`） | 无需账号 | 查看本人问题照片、上传/更换整改照片 |

> 首次登录后请到「设置」修改默认密码。

## 启动

```bash
npm install
npm start              # 默认 http://localhost:3000
PORT=8080 npm start    # 自定义端口
```

数据保存在 `data/db.json`，图片保存在 `uploads/`（均为原子写、自动生成，可直接备份）。

## 业务流程

1. **甲方管理员**在「员工管理」添加外包员工。
2. 在「录入考核」选择员工 → 填扣分项和分值 → 上传问题照片（JPG/PNG/WEBP/GIF，≤5MB，前端自动压缩）。
3. 在「整改链接」为员工生成专属链接/二维码（默认 72 小时有效，可在设置调整 1~2160 小时）。
   微信/短信发给员工；**重新生成会立即作废旧链接**。
4. **员工**手机扫码打开链接 → 对照问题照片 → 上传整改照片（可重新上传覆盖）。
5. **老板汇总页**按员工卡片展示：问题/整改图片对、扣分、总扣分、整改进度百分比，
   支持搜索、按扣分/待整改/进度排序、全部展开/收起。

## 错误提示（用户可读懂）

| 场景 | HTTP | 页面表现 |
| --- | --- | --- |
| 链接过期 | 410 | 员工页整屏提示「整改链接已过期」+ 到期时间 + 联系管理员重新发送 |
| 链接错误/被重置 | 401 | 「整改链接无效」+ 链接特征码，说明重新生成后旧链接失效 |
| 未带 token 手改网址 | 401 | 提示通过管理员发送的完整链接或二维码进入 |
| 图片超过 5MB | 413 | 中文提示大小上限；前端先自动压缩，仍超限给明确指引 |
| 伪造图片/格式不对 | 415 | 服务端校验 MIME + 文件头魔术字节，拒绝并提示 |
| 登录失效 | 401 | 顶部 toast 提示后自动跳登录页 |
| 老板执行写操作 | 403 | 「仅甲方管理员可执行此操作」 |
| 员工访问他人问题/图片 | 404/403 | 查不到问题、图片 403 |
| 网络中断 | — | 员工页/按钮均提示检查网络后重试 |

## 安全要点

- 密码 `scrypt + 随机盐`；会话为随机 token，HttpOnly Cookie，7 天滑动续期。
- 整改链接 token 为 48 位随机十六进制；仅可访问**本人**的问题与图片。
- 图片接口必须携带有效登录态或本人有效 token，否则 403。
- 上传文件名随机化、路径穿越防护（`path.basename`）、真实图片头校验。
- 所有 HTML 渲染经 `escapeHtml` 转义。

## 目录结构

```
src/
  server.js        Express 入口、图片鉴权、页面路由、错误兜底
  db.js            JSON 持久化数据层（账号/员工/问题/token/会话/统计）
  auth.js          登录态与员工 token 鉴权中间件
  upload.js        multer 上传：大小/格式/文件头校验
  routes/
    auth.js        登录、登出、当前用户、改密码
    admin.js       员工、考核问题、整改链接二维码、汇总、设置
    employee.js    员工查清单、上传整改照片
public/
  login.html  admin.html  boss.html  e.html  403.html
  css/common.css   设计系统
  js/              各页面逻辑 + 通用 API/Toast/灯箱/图片压缩
```
